# PINN Separator Simulation

Физически информированная нейронная сеть (PINN) для моделирования динамики двухфазного нефтегазового сепаратора с учётом парожидкостного равновесия (ПЖР).

*Physics-informed neural network for simulating a two-phase oil & gas separator with vapor–liquid equilibrium. Master's thesis, Gubkin University.*

---

## О проекте

Состояние сепаратора описывается системой дифференциально-алгебраических уравнений:

- **баланс компонентов**: dνᵢ/dt = F·z_in,i − V·yᵢ − L·xᵢ
- **парожидкостное равновесие**: закон Рауля–Дальтона (kᵢ = Pᵢ⁰(T)/P, давление насыщенных паров по Антуану) и уравнение Речфорда–Райса
- **условие заполнения объёма**: V_gas + V_liq = V_sep. Из него определяется давление в аппарате (VT-flash)

В проекте два решателя:

1. **Классический (эталон)**: явный метод Эйлера по балансу компонентов и VT-flash методом Ньютона на каждом шаге.
2. **PINN**: нейросеть `t → (ν₁…νₙ, P, ω)`. Все уравнения модели входят в функцию потерь как невязки, а производные считаются автодифференцированием. Для прямой задачи данные не нужны.

PINN решает две задачи:

- **прямая**: расчёт динамики P, уровня жидкости h и мольной доли газа ω по уравнениям модели;
- **обратная**: по зашумлённым замерам давления сеть восстанавливает неизвестный коэффициент газового клапана K_gas.

## Структура репозитория

```
├── separator_baseline.py   # эталонный симулятор: Антуан → Речфорд–Райс → VT-flash → Эйлер
├── separator_pinn.py       # PINN на JAX: прямая и обратная задачи
├── baseline.npz            # результаты эталона (создаётся скриптом)
├── pinn_forward.png        # сравнение PINN и эталона, прямая задача
└── pinn_inverse.png        # сравнение PINN и эталона, обратная задача
```

## Запуск

```bash
python separator_baseline.py          # эталонное решение -> baseline.npz, baseline.png
python separator_pinn.py              # прямая задача -> pinn_forward.png
python separator_pinn.py --inverse    # обратная задача -> pinn_inverse.png
```

Число итераций можно изменить флагами `--adam` и `--lbfgs`, например `--adam 1500 --lbfgs 300` для быстрой проверки.

## Метод

- **Архитектура**: MLP 4×64, активация tanh.
- **Жёсткие начальные условия**: ν(t) = ν₀·exp(τ·NN) и P(t) = P₀·exp(τ·NN), поэтому начальные условия выполняются точно, а величины остаются положительными. ω = sigmoid(NN), то есть 0 < ω < 1.
- **Функция потерь**: невязка баланса компонентов, невязка Речфорда–Райса и невязка условия объёма с весом 10. В обратной задаче к ним добавляется ошибка по замерам давления.
- **Обезразмеривание**: время τ = t/t_end, расходы нормированы на F, давление на P₀.
- **Сэмплинг точек коллокации**: половина точек приходится на первые 10% времени. Там идёт быстрый переходный процесс по давлению (задача жёсткая, с двумя масштабами времени).
- **Оптимизация** в два этапа: Adam с пересэмплированием точек на каждом шаге, затем дошлифовка L-BFGS на фиксированном наборе точек.

## Ограничения и дальнейшая работа

- Коэффициенты Антуана и плотности компонентов при 20 °C иллюстративные. Для метана и пропана при 300 K уравнение Антуана экстраполировано за пределы применимости.
- Параметры аппарата и обвязки заданы условно, клапаны линейные, регуляторов нет, температура постоянна.
